# 生产流水线

> 从客户下单到工厂上机的完整流程，以及每个环节的质量闸门。

## 1. 五道闸门

```
客户上传
   │
   ├─ 闸门 1：可生成性 ──── 图片分辨率/格式/内容是否可识别
   │
   ├─ 闸门 2：规格匹配 ──── 产品针数/色数能否表达这个内容
   │
   ├─ 闸门 3：工艺可行 ──── 最小色块 >= 机器可织极限，颜色在实际纱线色板内
   │
   ├─ 闸门 4：生产就绪 ──── 输出针数级设计文件（不是图片），附工艺参数
   │
   └─ 闸门 5：人工确认 ──── 生产前预览 + 客户确认记录
```

### 闸门 1：可生成性

| 检查 | 不通过的处置 |
|---|---|
| 文件格式（JPG/PNG/HEIC/WebP） | 提示转换格式 |
| 文件大小（≤10MB） | 提示压缩 |
| 主体可辨识 | 提示换图 |

### 闸门 2：规格匹配

系统读取产品规格后判断内容复杂度是否超出表达力。超出时有两种处置：

- **强约束重生成**：把规格写进生成条件，让模型按能力作画
- **主动降级**：小件产品禁用场景背景，只保留单主体

### 闸门 3：工艺可行

| 检查 | 阈值（示例） |
|---|---|
| 最小色块 | ≥ 画布宽度 ÷ 40（大件）～ ÷ 20（小件） |
| 颜色数量 | ≤ min(画布容量, 产品工艺上限) |
| 颜色值 | 必须落在该产品的实际纱线色板内 |

不通过的碎块在归一阶段被合并到相邻主色。

### 闸门 4：生产就绪

输出物不是「一张好看的图」，而是：

- 针数级设计文件（BMP，每像素 = 一针）
- 工艺参数：针数、色数、纱线色值、针织方法
- 与成品图对应的位置信息

### 闸门 5：人工确认

- 生产预览（含实际产品合成图）
- 客户确认的设计存档
- 生产工单自动投递给工厂

## 2. 两条并行的内容路径

| | 照片 | 手绘稿 |
|---|---|---|
| 路径 | AI 重绘 | 先识别内容类型 |
| 文字/图标 | — | 字体排版（可改字、边缘清晰） |
| 图形/插画 | AI 重绘 | AI 重绘（带识别出的主体名做提示） |
| 保真度 | 重新设计 | 文字路径 100% 保真 |

## 3. 质量指标（我们实际监控的）

| 指标 | 含义 | 目标 |
|---|---|---|
| 碎块密度 | 小于 12 针的孤立色块数 / 总针数 | 0 |
| 变化率 | 相邻像素不同的比例，衡量图案复杂度 | 小件 < 8% |
| 主体填充率 | 主体包围盒占画布比例 | ≥ 60% |
| 换色隔离度 | 换一色时其他颜色的像素变化 | 0.0% |
| 还原精确度 | 一键还原与原始设计的像素差 | 0 |

## 4. 交付物

一次订单最终产出：

1. **客户视角**：合成预览图、可修改的设计链接
2. **生产视角**：针数级设计文件 + 工艺参数表
3. **运营视角**：订单记录、成本核算、生产状态跟踪
