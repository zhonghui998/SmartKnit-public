# SmartKnit — AI 驱动的针织定制电商引擎

> 把任意一张照片或手绘稿，在 60 秒内变成「工厂能直接上机生产」的针织图案，并完成选品、换色、下单、生产交付的完整闭环。

---

## 一、解决什么问题

传统针织定制有四个断层，任何一环断了，生意就做不成：

| 断层 | 传统做法 | 我们的做法 |
|---|---|---|
| **照片 ≠ 图案** | 设计稿是照片，上机织出来糊成一团 | AI 按目标针织网格重绘，从生成阶段就按针数约束构图 |
| **图案 ≠ 工艺** | 图案好看但颜色数、线条粗细超出机器能力 | 生成前读取产品的针数/色数/工艺上限，按约束作画 |
| **客户看不懂** | 客户不知道 82 针能表达什么，反复退改 | 实时预览 + 逐色换色，所见即所得 |
| **订单 ≠ 生产** | 设计稿重新描图、工厂反复确认 | 直接输出工厂格式文件 + 自动生产工单 |

一句话：**把「设计语言」自动翻译成「机器语言」**。

## 二、产品能力

### 支持的产品线（30 个 SKU）

| 类别 | 代表产品 |
|---|---|
| 手提袋 / 托特 | 横款 / 竖款 / 斜背 / 迷你 |
| 电脑包 / 平板包 | 13"–16"、横竖两版 |
| 居家织物 | 杯垫、方巾、鼠标垫、挂毯 |
| 艺术打印 | A3 / A4 / A5 针织画 |
| 配件 | 钥匙扣、织带、行李牌、登机牌 |

### 核心能力

- **照片 → 针织图**：AI 重绘，自动适配目标针数（82×64 到 270×156）
- **手绘稿 → 针织图**：内容识别分流，文字走字体排版、图形走 AI 重绘
- **智能换色**：识别图案色块，逐块替换成真实纱线色，其他区域像素级不动
- **一键还原**：逐像素回到 AI 原始设计
- **实时预览**：合成到真实产品图上，含袋身底色联动
- **生产就绪**：直接输出针数级设计文件 + 自动生成生产邮件

## 三、技术架构

```
┌─────────────────────────────────────────────────────────────┐
│  前端定制器（浏览器内运行，无需安装）                          │
│  · 上传 / 拍照    · 实时预览    · 点图选区    · 换色面板       │
└──────────────────────────┬──────────────────────────────────┘
                           │ HTTP / JSON
┌──────────────────────────▼──────────────────────────────────┐
│  业务层 API                                                   │
│  · 产品模板驱动（30 个 SKU 的差异全部数据化）                  │
│  · 规格解析：针数 / 色数 / 色板 / 内容预算                     │
│  · 订单与 Shopify 集成    · 生产交付流水线                     │
└──────────────────────────┬──────────────────────────────────┘
                           │
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
┌───────────────┐  ┌───────────────┐  ┌───────────────┐
│ 内容识别       │  │ AI 生图        │  │ 针织化引擎     │
│ 视觉理解分流    │  │ 提示词工程      │  │ 网格量化 / 合成 │
│ 文字/图形判断   │  │ 画布比例约束    │  │ 区域识别 / 渲染 │
└───────────────┘  └───────────────┘  └───────────────┘
```

### 分层原则

- **产品模板数据化**：30 个 SKU 的针数、色数、工艺参数、合成位置全部由 JSON 驱动，新增产品不改代码
- **规格解析单一来源**：一处决定「这个产品能表达什么」，AI 生成、换色面板、生产输出共用同一份规格
- **生图与针织解耦**：AI 只负责「画得对」，针织引擎只负责「织得出」，各自独立演进

## 五、关键技术挑战（以及我们的解法方向）

### 1. 生成的信息量 vs 工艺的表达力

一张手机照片有 50 万种颜色，而杯垫只有 5,248 个针位（6 色）。信息损失 99.85%。

**这决定了一个产品逻辑：不能「先画再压」，必须「先定规格再画」**。系统在生图前先解析产品能表达的上限（针数、色数、最小色块、能否带场景），把它变成对 AI 的硬约束。

### 2. 同一组指令，AI 的产出波动 10 万倍

实测同一组提示词，模型有时输出 4 色干净图，有时输出 41 万色复杂图。

**靠提示词无法保证稳定**，所以引入了「生成后自适应简化」：量化碎块密度、不达标就加大简化强度重算，最终效果与模型的随机性解耦。

### 3. 换色不能让其他区域「跟着变」

早期实现里，换一个颜色整张图都变样——因为渲染层重绘了整图并叠加描边。

**解法是以原图像素为底，只替换目标颜色的格子**，区域内的暗部细节（描边、眼睛）一律保留。实测换天空色时，其他 5 个颜色的像素数变化为 0.0%。

### 4. 竖图塞进横画布

客户上传竖条长颈鹿到横款电脑袋，按比例裁切会丢掉 67% 内容。

**解法是双管齐下**：提示词里直接声明画布长宽比要求 AI 重排构图；归一阶段遇到极端比例改用等比放入而非裁切。
